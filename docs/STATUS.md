## 웹 UI 디자인

2026-10-25 · 방송 발견 서비스 2차 시안. 1차 대시보드 형태에 대한 피드백을 반영했다.

- 위치: `web/design-preview/`. 모노레포의 웹 영역은 `web/`로 분리한다. 서버는 현재 루트 Gradle·`src/` 구조이며 `server/` 이동과 제품 프런트엔드 기술 선택은 후속 작업이다.
- 화면: 큰 방송 썸네일과 탐색 버튼 → 급증 방송 목록 → 방송 카드 탐색. 상세 그래프와 집계 설명은 모달로 이동했다. 검색·카테고리·관심 방송 저장을 제공한다.
- 입력: 합성 채널·건수·시각·수집 상태만 사용한다. 썸네일은 내장 imagegen으로 제작한 가상 방송 이미지다. 실제 API 호출·급증 판정·live 검증은 수행하지 않았다.
- 실행: `./scripts/ui-preview` → `http://127.0.0.1:18081/`.
- 검증: 로컬 Chromium에서 검색·빈 결과·카테고리·관심 저장과 새로고침 후 유지·1분/5분 정렬·급증 선택·상세 모달·30분/1시간 추이·예시 방송 안내·집계 제외·기준 모달과 Escape 닫기 확인. 320/375/414/768/1280/1440px에서 본문과 모달 가로 넘침 없음, 페이지 JS 오류 없음.
- 정적 확인: `node --check web/design-preview/app.js`, `bash -n scripts/ui-preview`, `python3 scripts/check-doc-links.py` 통과. Java 변경이 없어 이번 작업에서 서버 테스트·JAR 빌드는 실행하지 않았다.
- 임시 캡처: `work/ui-design/`. 실제 데이터 연동, Safari·Firefox, 실기기 모바일은 미검증.
