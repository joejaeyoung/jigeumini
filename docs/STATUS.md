## 웹 UI 디자인

2026-10-25 · 상단 메뉴를 사용하는 웹사이트형 4차 시안. 방송 발견 서비스의 밝은 색상과 썸네일 중심 구성을 유지했다.

- 위치: `web/design-preview/`. 모노레포의 웹 영역은 `web/`로 분리한다. 서버는 현재 루트 Gradle·`src/` 구조이며 `server/` 이동과 제품 프런트엔드 기술 선택은 후속 작업이다.
- 화면: 상단 메뉴·공통 검색과 홈·방송 탐색·반응 급상승·관심 방송의 독립 화면. 모바일도 로고·검색 아래 상단 메뉴로 이동한다. 하단 고정 메뉴와 사이드바를 제거했다. 화면 정의와 공통 내비게이션은 `shell.js`, 기능 동작은 `app.js`, 레이아웃은 `platform.css`로 나눴다.
- 가독성: 방송 카드와 홈 대표 방송의 반응 태그를 높이 28px·숫자 14px의 V자 끝 리본으로 조정했다. 2배대는 청록, 3배 이상은 코랄로 구분하며 급상승 목록에도 같은 배수별 색상을 적용한다. 320/375/414/768/1024/1440px에서 태그 잘림·가로 넘침 없음, 상세 열기·닫기와 페이지 오류 없음 확인.
- 확장: 새 화면 등록에서 메뉴와 제목을 생성한다. 검색어·카테고리는 주소에 보존하며 뒤로 가기와 새로고침에서 복원한다. 상세 그래프와 집계 안내는 모달로 제공한다.
- 입력: 합성 채널·건수·시각·수집 상태만 사용한다. 썸네일은 내장 imagegen으로 제작한 가상 방송 이미지다. 실제 API 호출·급증 판정·live 검증은 수행하지 않았다.
- 실행: `./scripts/ui-preview` → `http://127.0.0.1:18081/`.
- 검증: 로컬 Chromium에서 메뉴별 본문 전환·공통 검색·뒤로 가기·직접 주소와 새로고침 복원·급상승 정렬·관심 저장과 해제·빈 상태·카테고리 바로가기·상세 모달과 Escape 닫기 확인. 4차 변경에서 320/375/414/768/1024/1440px 상단 메뉴 배치·화면 이동·검색을 확인했다. 가로 넘침과 하단 고정 메뉴 없음, 페이지 JS 오류 없음.
- 정적 확인: `node --check web/design-preview/app.js`, `node --check web/design-preview/shell.js`, `bash -n scripts/ui-preview`, `python3 scripts/check-doc-links.py` 통과. Java 변경이 없어 이번 작업에서 서버 테스트·JAR 빌드는 실행하지 않았다.
- 임시 캡처: `work/ui-design/`. 실제 데이터 연동, Safari·Firefox, 실기기 모바일은 미검증.
