# 웹 UI

모노레포의 웹 영역이다. 현재는 디자인 검토용 정적 시안만 있으며 실제 API를 호출하지 않는다.

```text
web/
  design-preview/   # 합성 데이터로 확인하는 화면·인터랙션 시안
```

서버는 현재 루트의 Gradle·`src/` 구조를 사용한다. 제품 프런트엔드 도입 시 `server/`와 `web/` 경계를 기준으로 서버 경로와 루트 `scripts/`를 함께 정리한다. 이번 디자인 작업에는 서버 이동이나 프런트엔드 프레임워크 결정이 포함되지 않는다.

실행 방법은 루트 README, 진행 상태는 `docs/STATUS.md`에서 관리한다.
